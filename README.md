# Freddy — CSN quoting co-pilot (prototype)

A voice-driven assistant for the Cargo Solutions Network portal. Single-file prototype: everything lives in `index.html`. Sample rates only — no backend, nothing is actually booked.

**Try it:** open the deployed link in Chrome, Edge or Safari, tap "Tap to talk to Freddy" and allow the microphone.

**Update it:** replace `index.html` and commit — Vercel redeploys automatically.
